# 現行Pythonデスクトップ版の参考コード

[legacy_desktop_form.py](legacy_desktop_form.py)は、芽室町で使っている申請書作成Python版7.6の処理を、設計議論で参照するためのコードです。公開にあたり、個人フォルダと内部資料の場所を示すコメントを除き、ファイル名を変更しています。処理内容は変更していません。

## 参照できる処理

- Tkinterによる対象者検索・世帯表示・対象者選択。
- SQLite／PostgreSQLの切替と、住民情報の直接取得。
- 住民票の記載事項の選択、宛名番号のクリップボードへのコピー。
- xlwingsによるPC上のExcelアプリの操作と、申請者・対象者・記載事項フラグのセルへの転記。

このコードは現行版の処理を知るための資料です。OSS版のアプリ実装や、合意済みの設計を示すものではありません。本籍の事前確認・印字制御など、今後の要求への対応状況は[方針・要求と構成の基本案](../requirements-and-design.md)と分けて確認してください。

## 実行環境と必要なファイル

Excelデスクトップアプリを利用できるWindows PCを前提とします。Python標準ライブラリに加え、pandas、numpy、xlwings、pyperclipが必要です。PostgreSQLを使う場合はpsycopg2も必要です。依存パッケージの版を固定した再現環境は、今回の掲載には含めていません。

実行には、コードが参照する列を持つDBと、セル位置が対応したExcel帳票が必要です。DB、実設定入りのINIは同梱していません。[参考用のExcel帳票](../assets/統一様式_標準化後.xlsx)は掲載していますが、このコードとは対象者の転記列に不一致があります。[対応関係と調整が必要な箇所](../materials.md#excel帳票と参考コードの対応)を確認してください。公開ファイルを取得しただけでは起動・正しい転記の条件は揃いません。

- 設定ファイル名は `申請書作成_db.ini`。スクリプトと同じフォルダ、なければ一つ上のフォルダを探します。
- `[database]` の `backend` でSQLite／PostgreSQLを選びます。SQLiteの既定パスは実行ユーザーのDesktop内の `resident_RDB.db` です。
- PostgreSQL接続情報はINIの `pg_host`、`pg_port`、`pg_dbname`、`pg_user`、`pg_password`、`pg_sslmode`、または対応する `MADO_PG_*` 環境変数から読みます。INIに値があればそちらが優先されます。
- Excel帳票は `[paths]` の `excel_path` で指定します。省略時はDesktop内の `統一様式.xlsx` です。
- 先頭シートの `T2`、`AJ2`、`BA2` などへ転記します。対応していない帳票で実行すると、既存セルを消去・上書きする可能性があります。

コードを読むことで、取得項目と転記順を確認できます。今回の公開用ファイルではPythonの構文確認を行いましたが、架空DB・対応帳票を揃えた一連の実行は確認していません。

## hubとの関係

この版はDBへ直接接続します。hubのログイン・権限・職員別監査を経由する実装ではありません。OSS版ではhubとどう連携するかを設計議論で検討します。また、Excelアプリを使わないサーバーへ、この処理をそのまま移す前提にはしません。

接続設定や住民データをGitHubへ追加しないでください。実行時の画面・ログにはパスや住民情報が表示されるため、共有する際は架空データを使い、接続情報等が含まれないことを確認してください。
