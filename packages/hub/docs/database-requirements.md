# データベース要件定義

> ⚠️ このメモは住民記録システム標準仕様書寄りのカラム定義を**検討段階のまま**含んでおり、一部の列名は同梱DDL（`packages/hub/prisma/init.sql`）と一致していない。実装が実際に参照する列名は [docs/REQUIREMENTS.md](../../../docs/REQUIREMENTS.md) の「住民データベースの要件」と `columns.json` を基準にすること。

> 🔒 **`個人番号`（マイナンバー）はこの要件に含まない。** MADO は個人番号を「値を空にする」のではなく**列そのものを持たせない**方針で、スキーマにもサンプルデータにも存在しない。日次取込スクリプト（[`tools/csv_import`](../../../tools/csv_import/README.md)）側でも取込対象から明示的に除外している。詳細は [docs/ARCHITECTURE.md](../../../docs/ARCHITECTURE.md#権限設計の現状と限界) を参照。

### 転入前住所

転入前住所は以下の2パターンが存在する。

**パターンA：分割記載**

| カラム名 | 説明 |
|---|---|
| 転入前_都道府県 | 都道府県名 |
| 転入前_市区郡町村名 | 市区郡町村名 |
| 転入前住所_町字 | 丁目まで記載 |
| 転入前住所_番地号表記 | 番地・号を別カラムに記載 |

**パターンB：町字にすべて記載**

| カラム名 | 説明 |
|---|---|
| 転入前_都道府県 | 空または省略 |
| 転入前_市区郡町村名 | 空または省略 |
| 転入前住所_町字 | 都道府県〜番地まですべてを含む |
| 転入前住所_番地号表記 | 空または省略 |

> 住所の完全表記は `転入前_都道府県` + `転入前_市区郡町村名` + `転入前住所_町字` + `転入前住所_番地号表記` を結合して得る。パターンBでは `転入前住所_町字` 単独で完全住所となる。

### 本籍

| カラム名 | 説明 |
|---|---|
| 本籍 | 本籍地（番地まで、または丁目までの2パターンあり） |
| 本籍_地番号 | 番地が `本籍` に含まれない場合の番地・号 |
| 本籍_街区符号 | 街区方式の場合の街区符号（地番号と排他） |

> 完全な本籍地は `本籍` + `本籍_地番号` または `本籍` + `本籍_街区符号` で構成される。

| カラム名 | 型 | 説明 |
|---|---|---|
| 戸籍_筆頭者 | TEXT | 戸籍筆頭者のフルネーム |

### 転出先住所（確定）

| カラム名 | 型 | 説明 |
|---|---|---|
| 転出先住所（確定）_郵便番号 | TEXT | 7桁数字・全角のみ（例: `１２３４５６７`） |
| 転出先住所（確定）_町字 | TEXT | 町字（丁目まで） |
| 転出先住所（確定）_番地号表記 | TEXT | 番地・号 |
| 転出先住所（確定）_方書 | TEXT | 方書（建物名・部屋番号等） |

> 完全な転出先住所は `転出先住所（確定）_町字` + `転出先住所（確定）_番地号表記` + `転出先住所（確定）_方書` を結合して得る。
